# Siddanth Rao — Engineering Portfolio

A static portfolio website. No installation, framework, or build step is required.

## Files
- index.html: main portfolio
- ares.html: detailed ARES project
- style.css: shared styling
- script.js: main-page project filters
- assets/: CAD images, previews, and project PDFs
- .nojekyll: tells GitHub Pages to serve the files directly

## Upload through GitHub
1. Extract this ZIP on your computer.
2. Create a repository on GitHub. For a personal homepage, name it YOUR-USERNAME.github.io, replacing YOUR-USERNAME with your actual GitHub username.
3. Choose Add file > Upload files. Upload the CONTENTS of this extracted folder, including the assets folder, so index.html is at the repository root. Commit the files.
4. For a public site on GitHub Free, the repository must be public. Review all portfolio content and PDFs before making it public. The L’SPACE technical details are still awaiting a disclosure decision.
5. Open repository Settings > Pages. Choose Deploy from a branch, then main and / (root), and Save.
6. GitHub will show the published website address when deployment completes.

The GitHub Import Repository screen is not needed for this ZIP. Upload files to a new repository instead.

Change the HTML to update text; replace assets to update images or PDFs. Keep relative file paths intact. The ARES page URL is ares.html. No ChatGPT hosting scripts or hosting configuration are included.
